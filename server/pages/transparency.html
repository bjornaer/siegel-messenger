The web app's code

A server that serves code could serve different code to someone. So every release of {{.WebHost}} lists the SHA-256 of each of its files in its manifest, and GitHub records (in the public Sigstore log) which commit of our source code it was built from. The manifest served now has the SHA-256 {{.Web}}. To check it yourself, run scripts/verify-web.sh from our source code; it compares every file you are served with the attested list.
